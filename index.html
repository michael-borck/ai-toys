AI Toys: small pages that break a misconception

Each one is a single self-contained page built to kill one specific wrong idea about AI and machine learning that slides reliably fail to kill. No install, no account, no network, no real model. Save the page and it still works. Companion to Security Toys.

Threshold Dial

Kills: “overall accuracy means it works”. The prettiest headline on the dial ships 29 of 50 faults, and a detector that detects nothing scores 95%; the threshold is a business decision about which error hurts more.

House rules

  • One file. No CDN, no fonts, no fetch; runs from a USB stick, uploads to an LMS as a single file.
  • One idea. If it needs a tutorial, it’s too big.
  • Ninety seconds. Playable from cold by someone who read no instructions.
  • A “wait, what?” moment. Named in every spec. If a build doesn’t produce it, it isn’t finished.
  • Nothing leaves the page. No storage, no analytics, no backend; every “model” is a seeded simulation.
