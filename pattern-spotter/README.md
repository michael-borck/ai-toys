# Pattern Spotter

Kills: **"the data speaks for itself."**

Three small charts, ninety seconds, and in every one more than one confident story fits the same
numbers: consistency or divide, season or failure, volume or ratio. The data never argues — your
interpretation does the work, using context the chart does not contain. That is the human-side
version of [k-means-stepper](../k-means-stepper/): before a machine imposes patterns on data, you
were already doing it.

Open `index.html`. Add `?present` for a projector. See `SPEC.md` to rebuild it from scratch.
