# Perceptron

Kills: **"AI decisions are mysterious."**

Three factors, three weights, one threshold. Set them, run the decision, and watch the whole
machinery: multiply, add, compare. Nothing else happens in there. Then change a weight with the
data untouched and watch the verdict flip — the decision was never hiding in the data; it lives
in the weights (what training tunes) and the threshold (what the business chooses). The scale
table finishes the argument: the same mechanic runs at every scale, from one neuron to frontier
LLMs. Scale changes how many run, not what a decision is made of.

Open `index.html`. Add `?present` for a projector. See `SPEC.md` to rebuild it from scratch.
