# Drift Compounds

Kills: **"95% reliable per step is basically reliable."**

A hundred runs of a 12-step agent workflow, every step an A-grade 95%: 54 arrive correct, 46
arrive polished, confident and silently wrong, because nothing ever crashes; drift just gets
built upon. Buying a 99% model still leaks ten. Checkpoints are the design surface: each one can
only verify the last three steps (older drift reads as foundation), so one big review at the end
scores no better than one mid-pipeline, and covering the rail takes placement, not diligence.

Open `index.html`. Add `?present` for a projector. See `SPEC.md` to rebuild it from scratch.
