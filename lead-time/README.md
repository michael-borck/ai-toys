# Lead Time

Kills: **"survival went up, so the treatment works."**

Twelve patients, same disease, same deaths in the same years. Drag the screening start earlier
and the headline statistics explode: average survival after diagnosis climbs, the "5-year
survival rate" hits 100% — and not a single death date moves. The extra "survival" is time
spent *knowing* about the disease, not time spent alive. This is **lead-time bias**, and it is
why the number that proves a screening programme is *mortality*, not survival.

The statistic that flatters: a survival rate measures where you started counting. The question
that deflates it: from when, and who chose the starting line?
