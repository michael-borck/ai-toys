# Scenario Sprint

Kills: **"technique selection is a technical detail the business never weighs."**

Four client briefs — hospital readmission, fintech credit risk, supermarket dynamic pricing,
mining equipment failure. Each team takes one client, frames the problem, chooses and tests a
technique, and defends the recommendation in a three-minute pitch. The briefs are engineered so
the decisive constraint differs per client: explainability, fairness, real-time framing, and
error-cost asymmetry (3% failure rate makes "97% accuracy" a live trap).

A team challenge by design: 3–5 people, one 60-minute block — 45 minutes of work, 15 minutes
of pitches.
