# Scenario Sprint

**Class activity** (the collection's one instructor-led page): teams of 3–5, one 60-minute
block. Kills: **"technique selection is a technical detail the business never weighs."**

Four Australian client briefs — hospital readmission, fintech credit risk, supermarket dynamic
pricing, mining equipment failure. Each team takes one client, frames the problem, chooses and
tests a technique, and defends the recommendation in a three-minute pitch. The briefs are
engineered so the decisive constraint differs per client: explainability, fairness, real-time
framing, and error-cost asymmetry (3% failure rate makes "97% accuracy" a live trap).

Deliberately not a solo toy: it needs teams, a facilitator, and tool work — which is why it is
the one page here that breaks house rule 3, openly.

Open `index.html`. Add `?present` for the projector (it is designed for one). See `SPEC.md` to
rebuild it from scratch.
