# Technique Picker

Kills: **"there is a default AI technique."**

Five clients, five briefs, five different right answers from the same toolkit. A bank asking
"how much?", a hospital that must be able to audit every call, a review corpus a thousand
features wide, a marketing team wanting accuracy *and* drivers, a mining dataset whose biggest
gap is the failure it is supposed to predict. The business question, the constraints, and the
shape of the data pick the model — every time.

The five rules surface as you play: question type, stakes vs interpretability, data shape,
accuracy-and-insight compromises, and checking the data contains the outcomes you are predicting
(including the failures — the mining brief is a survivorship-bias trap).

Open `index.html`. Add `?present` for a projector. See `SPEC.md` to rebuild it from scratch.
