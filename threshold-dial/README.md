# Threshold Dial

Kills: **"overall accuracy means it works."**

A thousand units, fifty faults, one slider. The highest headline accuracy on the dial (96.5%)
ships 29 of the 50 faults, and a detector that flags nothing at all scores 95%: the headline
cannot tell working from dead. Slice by production line to watch the same headline hide a 4×
recall gap, then price the two mistakes and find the threshold that actually matters.

Open `index.html`. Add `?present` for a projector. See `SPEC.md` to rebuild it from scratch.
